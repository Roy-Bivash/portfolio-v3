# Game of Life — Simulation d’automate cellulaire dans le navigateur

**Description**  
Game of Life est une implémentation de Conway’s **Game of Life**, une simulation d’automate cellulaire qui s’exécute dans le navigateur. L’interface est construite avec React, tandis que le rendu de la grille et la logique du jeu reposent sur le framework **Phaser**.

**Fonctionnalités**
- Lancer la simulation.
- Mettre la simulation en pause.
- Réinitialiser la grille.
- Remplir la grille avec un motif aléatoire.
- Activer ou désactiver une cellule individuellement en cliquant dessus.

**Stack technique**
- React : interface utilisateur et structure des composants.
- Phaser : rendu de la grille et logique du jeu.
- TypeScript : typage et confort de développement.
- CSS : mise en forme de l’application.

**Ce que le projet démontre**
- Mise en œuvre d’une simulation d’automate cellulaire dans le navigateur.
- Intégration de React pour l’interface et de Phaser pour le rendu et la logique de jeu.
- Gestion d’interactions simples et directes : lancer, pause, reset, motif aléatoire et clic sur les cellules.
- Utilisation de TypeScript pour structurer le code.

**Portée**  
Projet volontairement simple et centré sur la simulation, les contrôles de base et l’intégration React/Phaser.
