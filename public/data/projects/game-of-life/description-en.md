# Game of Life - Browser-based Cellular Automaton Simulation

**Overview**  
Game of Life is an implementation of Conway’s **Game of Life**, a cellular automaton simulation that runs in the browser. The UI is built with React, while grid rendering and game logic are handled by the **Phaser** game framework.

**Features**
- Run the simulation.
- Pause the simulation.
- Reset the grid.
- Fill the grid with a random pattern.
- Toggle individual cells between alive and dead by clicking them.

**Technical stack**
- React: UI and component structure.
- Phaser: grid rendering and game logic.
- TypeScript: type safety and development experience.
- CSS: application styling.

**What this project demonstrates**
- Implementation of a cellular automaton simulation in the browser.
- Integration of React for the UI and Phaser for rendering and game logic.
- Handling simple, direct interactions: run, pause, reset, random pattern, and cell toggling.
- Use of TypeScript to structure the code.

**Scope**  
A deliberately simple project focused on the simulation, basic controls, and React/Phaser integration.
