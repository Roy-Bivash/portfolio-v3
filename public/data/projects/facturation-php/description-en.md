**Project Title:** Client Invoicing and Billing Application

**Description:**
During my BTS internship, I developed a comprehensive web application to manage client invoicing. Built with PHP, MySQL, and Bootstrap for functionality and front-end, the core feature is the automated generation of professional invoices in PDF format. To achieve this reliable output, I integrated the **`html2pdf`** library, efficiently converting structured HTML into clean, printable documents.

**Technologies Used:** PHP, MySQL, Bootstrap, **html2pdf**
